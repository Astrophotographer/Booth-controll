# 부스관제

행사 부스의 혼잡 상태와 요청을 관리하는 웹 앱입니다. 부스와 관제 화면, 대화, PWA 및 웹 푸시 알림을 제공합니다.

## 실행

Node.js를 설치한 뒤 다음 명령을 실행합니다.

```sh
npm ci
VAPID_SUBJECT=mailto:admin@example.com npm start
```

브라우저에서 `http://localhost:8787`을 엽니다. `PORT` 환경변수로 포트를 바꿀 수 있습니다. 웹 푸시를 운영할 때는 `VAPID_SUBJECT`에 관리자의 연락 가능한 `mailto:` 주소나 HTTPS 주소를 지정하세요. 모바일 PWA와 푸시는 HTTPS 환경이 필요하며, iPhone 푸시는 홈 화면에 추가한 웹 앱에서 알림을 허용해야 합니다.

부스 데이터, 푸시 구독 및 VAPID 키는 실행 중 `data/`에 생성됩니다. 이 디렉터리와 환경변수 파일은 Git에 포함하지 않습니다. 운영 데이터와 키는 별도로 백업하세요.

현재 앱에는 로그인 및 접근 제어가 없습니다. 네트워크에 공개하기 전에 사용 환경에 맞는 접근 제어를 적용하세요.
